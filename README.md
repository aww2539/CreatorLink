# Creator Link - Elixir

### Original NSS Capstone Project Rebuilt With An Elixir Backend

CreatorLink offers a one-stop shop for users to find all their favorite content creators’ links, follow their favorite creators for quick, easy access,  and keep up to date with what they are working on. 

## Tech

- Frontend: Javascript, React, MaterialUI

- Backend: Elixir, Phoenix, Ecto

- Database: PostgreSQL
